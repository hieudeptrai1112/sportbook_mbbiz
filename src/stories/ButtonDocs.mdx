# Button

Primary action component for forms and dialogs.

## Overview

Use for primary and secondary actions. Avoid multiple primary buttons in a
single view.

## Variants

- Primary
- Secondary
- Ghost
- Danger

## Usage Guidelines for Designers

- Use Primary for the main action.
- Keep label concise (1–3 words).
- Place primary action to the right in modals.

## Usage Guidelines for Developers

- Use `type="submit"` only inside forms.
- Use `aria-label` for icon-only buttons.

## Accessibility

- Keyboard focus visible.
- Minimum 44px height for touch.
- Ensure contrast meets WCAG AA.

## Spacing

- Default padding: 12px 16px.
- Gap between buttons: 8px.

## Examples

- Primary button for “Save”.
- Secondary for “Cancel”.
- Ghost for toolbar actions.

## Copyable Code

```ts
<button class="mbbtn mbbtn--primary">Save</button>
```
