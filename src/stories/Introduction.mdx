# MBBiz DS

MBBiz DS is the internal design system that aligns designers and developers
around a single source of truth. This Storybook is the documentation hub for
tokens, guidelines, components, and usage patterns.

## What you can find here

- Design Tokens: color, typography, spacing, and elevation definitions
- Design Guidelines: layout rules, motion, and accessibility
- Components: reusable UI building blocks
- Component Usage: patterns and best practices
- Development Guide: Angular setup and release workflow

## How to use this site

Start with Design Tokens and Design Guidelines to understand the foundations,
then move into Components and Component Usage for implementation patterns.
Developers can copy code snippets directly from component pages.
