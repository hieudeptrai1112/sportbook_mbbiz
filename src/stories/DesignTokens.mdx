# Design Tokens

Tokens are the foundation of the system and the single source of truth for
visual values.

## Scope

- Color: brand, semantic, neutral
- Typography: font families, sizes, weights, line heights
- Spacing: scale for margins and paddings
- Elevation: shadows and layers

## Usage

Designers maintain tokens in Figma. Developers consume tokens as CSS variables
or TypeScript constants for Angular components.
