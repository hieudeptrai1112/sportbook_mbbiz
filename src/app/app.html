Getting Started / Installation

Installation

Install Sportbook6vn from npm, load the theme once, then import only the standalone components needed by each Angular page.

Install Package

The published package is sportbook6vn@0.0.1. Install it in the Angular application that consumes the component library.

npm 
{{ installationInstallCommand }}

Angular and NG-Zorro are peer dependencies. Install them only when the host app does not already provide compatible versions.

peer dependencies 
{{ installationPeerCommand }}

Import Style

Load the Sportbook6vn tokens and NG-Zorro bridge once in the global stylesheet. Keep product-level overrides after these imports.

styles.scss 
{{ installationThemeCode }}
theme.css semantic tokens zorro-bridge.less NG-Zorro variables

Import Component

Sportbook6vn exports standalone Angular components. Import only the components used by the current page or feature module.

app.component.ts 
{{ installationUsageCode }}

Next Step

Open the target component page, choose the matching case, and copy the snippet from that page. Keep implementation imports from sportbook6vn so the app stays on one source of truth.

Input Field

Real Sportbook6vn input components mapped 1:1 from the approved preview Input family / docs-ready draft. Input Tag is intentionally excluded because it has independent tag creation and validation behavior.

TS
{{ getInputDocsCodeLanguageLabel(sectionId) }} {{ getInputDocsCodeHint() }}

Basic Text Input

Baseline text entry with real hover, focus, typing, and filled behavior from the component runtime.

selector=sportbook6vn-input placeholder=Input text status=default

Affix Input / Prefix

Text input with a fixed prefix slot for compact currency or unit hints.

selector=sportbook6vn-affix-input mode=prefix

Affix Input / Prefix + Suffix

Text input with both prefixText and suffixText slots.

selector=sportbook6vn-affix-input mode=both

Search Input

Search field with clear and submit actions. The clear icon removes the current text value.

selector=sportbook6vn-search-input allowClear=true

Password Input

Password field with a visible toggle. Default state starts empty and interaction drives the filled state.

selector=sportbook6vn-password-input visible=false

Textarea

Multiline text input with maxLength counter and fixed visual shell.

selector=sportbook6vn-textarea rows=4 maxLength=100

Floating Label Input

Input with an inside label that stays within the field shell.

selector=sportbook6vn-floating-label-input label=Title

Affix Label Input

Currency selector inside the input shell. The demo keeps the trigger default; droplist interaction is verified from the component itself.

selector=sportbook6vn-affix-label-input prefixDropdownItems

Checkbox

Checkbox lets users select one or many options. This page keeps the approved preview cases for sportbook6vn-checkbox and sportbook6vn-checkbox-group in one dedicated component tab.

Basic

There are unchecked, checked, and indeterminate checkbox states.

selector=sportbook6vn-checkbox state=default/checked/indeterminate

Disabled

Disabled checkboxes keep visual state but block selection.

selector=sportbook6vn-checkbox disabled=true

Checkbox Group

Checkbox group allows multiple selected options in a horizontal layout.

selector=sportbook6vn-checkbox-group direction=horizontal

Select All

Select all becomes indeterminate when only part of the group is selected.

selector=sportbook6vn-checkbox indeterminate=true group=valueChange

Vertical Checkbox Group

Vertical group keeps the same multi-select behavior with stacked options.

selector=sportbook6vn-checkbox-group direction=vertical
