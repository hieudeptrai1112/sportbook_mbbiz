Input Field

Real Sportbook6vn input components mapped 1:1 from the approved preview Input family / docs-ready draft. Input Tag is intentionally excluded because it has independent tag creation and validation behavior.

TS
{{ getInputDocsCodeLanguageLabel(sectionId) }} {{ getInputDocsCodeHint() }}

Basic Text Input

Baseline text entry with real hover, focus, typing, and filled behavior from the component runtime.

selector=sportbook6vn-input placeholder=Input text status=default

Affix Input / Prefix

Text input with a fixed prefix slot for compact currency or unit hints.

selector=sportbook6vn-affix-input mode=prefix

Affix Input / Prefix + Suffix

Text input with both prefixText and suffixText slots.

selector=sportbook6vn-affix-input mode=both

Search Input

Search field with clear and submit actions. The clear icon removes the current text value.

selector=sportbook6vn-search-input allowClear=true

Password Input

Password field with a visible toggle. Default state starts empty and interaction drives the filled state.

selector=sportbook6vn-password-input visible=false

Textarea

Multiline text input with maxLength counter and fixed visual shell.

selector=sportbook6vn-textarea rows=4 maxLength=100

Floating Label Input

Input with an inside label that stays within the field shell.

selector=sportbook6vn-floating-label-input label=Title

Affix Label Input

Currency selector inside the input shell. The demo keeps the trigger default; droplist interaction is verified from the component itself.

selector=sportbook6vn-affix-label-input prefixDropdownItems

Core-3 Mapping

Bản tổng hợp trạng thái mapping từ preview sang app chính. Các component đã tách sang trang docs riêng sẽ chỉ còn được ghi nhận tại đây để tránh duplicate nội dung.

Input Family Mapping

Đã tách sang tab Input Field theo cấu trúc component docs riêng. Input Tag vẫn giữ ngoài Input family để mapping thành trang docs độc lập.

source=preview component=input-family target=Input Field excludes=input-tag

Moved to component docs

  • Use Input Field for the full docs page, API, status contract, and component token references.
  • Keep this Core-3 tab as a mapping index only, not as a second source of truth.
  • Map Input Tag separately after its preview draft is approved.

Input Tag Mapping

Đã tách sang tab Input Tag theo cấu trúc component docs riêng. Core-3 Mapping chỉ giữ lại trạng thái để tránh duplicate source of truth.

source=preview component=input-tag target=Input Tag status=split

Moved to component docs

  • Use Input Tag for interactive, overflow, render tag, validation, error, disabled, API, and component token docs.
  • Keep this Core-3 tab as the mapping index only.

Dropdown Family Mapping

Đã tách sang tab Dropdown theo cấu trúc component docs riêng. Core-3 Mapping chỉ giữ trạng thái để tránh duplicate source of truth.

source=preview component=dropdown-family target=Dropdown status=split

Moved to component docs

  • Use Dropdown for single select, multiple select, tag select, inside label, searchable droplist, tag droplist, status, disabled, empty states, API, and component token docs.
  • Keep this Core-3 tab as the mapping index only.

Dropdown Family Mapping

Mapping 1:1 từ preview cho component sportbook6vn-dropdown và sportbook6vn-dropdown-tag. Các trigger giữ trạng thái đóng/default; droplist chỉ xuất hiện khi user tương tác thật.

source=preview component=dropdown-family target=Core-3 Mapping status=mapped
