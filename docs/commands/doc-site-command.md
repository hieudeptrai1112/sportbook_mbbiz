# Documentation Site Command Rules

## Context
We are building a design system documentation site in Cursor.

## Purpose
Use this command file when building or updating the documentation site shell, navigation, and global documentation behavior.

## Required Rules
- The documentation site must include a persistent sidebar for navigation.
- The sidebar must remain visible while scrolling through documentation pages.
- Sidebar category labels must be sorted in alphabetical order (A -> Z).
- Sidebar categories and page lists inside each category must be sorted alphabetically (A -> Z).
- Documentation pages must avoid non-system UI mockups.
- Documentation pages must focus on reusable design system patterns.
- Developers must be able to select and copy examples directly from the documentation.

## Build Acceptance Checklist
- [ ] Sidebar is persistent and visible while scrolling.
- [ ] Category labels are alphabetically ordered (A -> Z).
- [ ] Category groups and item lists are alphabetically ordered (A -> Z).
- [ ] No non-system mockup content is published.
- [ ] Reusable patterns are prioritized over one-off UI examples.
- [ ] Copy-friendly example content exists and can be selected and copied.
