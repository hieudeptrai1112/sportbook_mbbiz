# Component Pages Command Rules

## Context
We are building component documentation pages for a design system documentation site in Cursor.

## Purpose
Use this command file when creating or updating documentation for a specific component.

## Required Sections (All Mandatory)
Each component documentation page must include all of the following:
1. Overview
2. Variants and all visual options
3. Usage guidelines for both designers and developers
4. Accessibility considerations
5. Spacing rules and guidance
6. Implementation examples
7. Copy-enabled code snippets for builders

## Rules for Content Quality
- Variants must include the supported visual states and options.
- Usage guidance must cover both design usage and developer implementation.
- Accessibility guidance must be actionable.
- Examples must represent reusable system patterns.
- Code snippets must be directly selectable and copyable.

## Publish Acceptance Checklist
- [ ] All required sections are present.
- [ ] Variants and visual options are documented clearly.
- [ ] Designer and developer usage guidance is present.
- [ ] Accessibility guidance is included.
- [ ] Spacing rules are documented.
- [ ] Implementation examples are included.
- [ ] Code snippets are copy-enabled.
